# 安全规范

> 来源：Team Harness V1.0 PRD §6.1 / §6.5。命中即为 Critical。

## 1. 敏感信息（强制红线）

- 禁止硬编码密码、Token、Access Key、私钥、连接串中的明文密码。
- 敏感配置走环境变量 / 配置中心 / Vault，不得入仓库。
- 禁止把密钥写进测试用例或日志。

## 2. 参数校验

- 所有外部入参必须校验（类型、长度、范围、格式），见 `api.md`。
- 永远不信任前端传值。

## 3. 数据泄露

- 日志禁止打印完整身份证、手机号、银行卡、密码、Token；脱敏后再打。
- 接口返回禁止携带不应暴露的字段（密码 hash、内部 ID 等），用 DTO 裁剪输出。

## 4. 权限

- 接口必须鉴权；越权检查（用户只能操作自己的数据）不得遗漏。
- 幂等 / 重放敏感操作必须校验。

## 5. 注入防护

- SQL 一律参数化（MyBatis `#{}`）。
- `${}` 仅可用于动态表名 / 列名，且必须经过白名单校验；禁止用于拼接值。
