# Prompt 模板 — Code Review

> 审查对象：当前 `git diff`。维度与细则见 `.ai/rules`（质量 / 性能 / 安全）。

## 审查维度

- **代码质量**：重复代码、可维护性、命名、分层是否越界。
- **性能**：SQL 性能、循环内调用、N+1、缓存使用。
- **安全**：参数校验、数据泄露、权限、SQL 注入（命中即 Critical）。

## 输出格式（每条问题）

```
问题等级：Critical / Major / Minor
文件：xxx.java:行号
问题：一句话描述
建议：具体修改建议
```

## 约束

- 只 review diff 内的改动，不扩散到未变更代码。
- 给出可执行建议，不泛泛而谈。
