# 业务说明 — hybrid-service-example

## 业务概述

本项目是税金计算服务，同时提供 HTTP API（同步）和 MQ 消息处理（异步）两种接入方式，为订单系统提供税金计算能力。

---

## 税种与计算规则

### 支持的税种

| 税种 | 税率范围 | 计算方式 | 说明 |
|------|----------|----------|------|
| 增值税（VAT） | 13% / 9% / 6% / 3% / 1% | 不含税金额 × 税率 | 根据商品类目适用不同税率 |
| 消费税 | 5% - 45% | 含税金额 × 税率 / (1 + 税率) | 仅特定类目商品 |
| 城建税 | 7% / 5% / 1% | 增值税额 × 税率 | 根据地区确定税率 |
| 教育费附加 | 3% | 增值税额 × 税率 | 全国统一 |
| 地方教育附加 | 2% | 增值税额 × 税率 | 全国统一 |

### 增值税税率适用规则

| 税率 | 适用场景 | 示例商品 |
|------|----------|----------|
| 13% | 一般货物销售、进口 | 电子产品、服装、食品 |
| 9% | 交通运输、农产品、图书 | 物流服务、农产品、出版物 |
| 6% | 现代服务业、金融服务 | 咨询服务、技术服务 |
| 3% | 小规模纳税人 | （简易征收） |
| 1% | 小规模纳税人优惠 | （阶段性优惠） |

### 纳税人身份规则

| 身份 | 增值税计算方式 | 附加税基数 |
|------|---------------|------------|
| 一般纳税人 | 销项税额 - 进项税额 | 实际缴纳增值税额 |
| 小规模纳税人 | 不含税销售额 × 征收率 | 实际缴纳增值税额 |

### 计算示例

```
场景：一般纳税人，销售电子产品（13%），含税金额 1000 元

不含税金额 = 1000 / (1 + 0.13) = 884.96 元
增值税额 = 884.96 × 0.13 = 115.04 元
城建税（市区 7%）= 115.04 × 0.07 = 8.05 元
教育费附加（3%）= 115.04 × 0.03 = 3.45 元
地方教育附加（2%）= 115.04 × 0.02 = 2.30 元
附加税合计 = 8.05 + 3.45 + 2.30 = 13.80 元
税金总计 = 115.04 + 13.80 = 128.84 元
```

## 税率配置管理

### 税率数据模型

| 实体 | 说明 | 关键字段 |
|------|------|----------|
| TaxRate | 税率配置 | id, taxType, regionCode, categoryCode, rate, taxpayerType, effectiveTime, expireTime, status |
| TaxRateHistory | 税率变更历史 | id, taxRateId, oldRate, newRate, operator, changeTime, reason |

### 税率查询规则

1. **查询维度**：税种 + 地区编码 + 商品类目编码 + 纳税人身份
2. **精确匹配**：优先匹配「地区 + 类目」级别的税率，其次匹配「地区」级别，最后匹配「全国默认」级别
3. **时间有效性**：查询时校验 `effectiveTime <= now < expireTime`（expireTime 为空表示永久有效）
4. **状态校验**：仅 `ACTIVE` 状态的税率配置可用

### 缓存策略

```
查询税率
    │
    ▼
Redis 缓存（key: tax:rate:{taxType}:{regionCode}:{categoryCode}:{taxpayerType}）
    │
    ├── 命中 ──► 返回缓存数据
    │
    └── 未命中
        │
        ▼
    查询 DB（按精确度优先级匹配）
        │
        ├── 找到 ──► 写入 Redis（TTL 1h）──► 返回
        │
        └── 未找到 ──► 返回默认税率 / 抛出业务异常
```

### 税率变更流程

```
管理员调用 HTTP 接口更新税率
    │
    ▼
校验权限 + 参数
    │
    ▼
写入 TaxRateHistory 变更记录
    │
    ▼
更新 TaxRate 配置
    │
    ▼
刷新 Redis 缓存（删除旧 key，写入新值）
    │
    ▼
发送 MQ 通知（Topic: tax-rate-change，广播模式）
    │
    ▼
下游服务消费通知 → 刷新本地缓存
```

### 生效模式

| 模式 | 说明 | 实现方式 |
|------|------|----------|
| 立即生效 | 变更后立即对所有新请求生效 | 更新 DB + 刷新缓存 + MQ 通知 |
| 定时生效 | 在指定时间点自动生效 | 定时任务扫描 `effectiveTime`，到期后自动激活 |

## MQ 消息流

### 消费：税金计算请求

```
订单服务 ──► RocketMQ (tax-calculate-request)
                    │
                    ▼
            ┌─────────────────┐
            │ TaxCalculate    │  消费消息
            │ RequestConsumer │
            └────────┬────────┘
                     │
                     ▼
              查询税率配置
                     │
                     ▼
              计算税金
                     │
                     ▼
              发送计算结果消息
                     │
                     ▼
            RocketMQ (tax-calculate-result)
                     │
                     ▼
            ┌─────────────────┐
            │ 订单服务消费     │  更新订单税金
            └─────────────────┘
```

### 消息体结构

**tax-calculate-request（请求）**：

```json
{
  "orderId": "ORDER202607270001",
  "amount": 1000.00,
  "taxType": "VAT",
  "regionCode": "110000",
  "categoryCode": "ELECTRONICS",
  "taxpayerType": "GENERAL",
  "traceId": "trace-abc-123"
}
```

**tax-calculate-result（结果）**：

```json
{
  "orderId": "ORDER202607270001",
  "taxType": "VAT",
  "taxRate": 0.13,
  "amountExcludingTax": 884.96,
  "taxAmount": 115.04,
  "surcharges": [
    { "name": "城建税", "rate": 0.07, "amount": 8.05 },
    { "name": "教育费附加", "rate": 0.03, "amount": 3.45 },
    { "name": "地方教育附加", "rate": 0.02, "amount": 2.30 }
  ],
  "totalTaxAmount": 128.84,
  "traceId": "trace-abc-123"
}
```

### 幂等策略

- **幂等 key**：`MD5("tax-calculate-request" + ":" + orderId + ":" + taxType)`
- 消费前查 Redis 幂等表，存在则跳过
- 计算完成后写入幂等表，TTL 72h
- 兜底：Redis 不可用时查 DB 幂等表

## 异常处理

### HTTP API 异常

| 异常类型 | HTTP 状态码 | 错误码 | 处理 |
|----------|------------|--------|------|
| 参数校验失败 | 400 | `TAX_400` | 返回字段级错误信息 |
| 税率未配置 | 404 | `TAX_404` | 返回未配置的税率维度信息 |
| 计算溢出 | 422 | `TAX_422` | 返回计算异常详情 |
| 系统异常 | 500 | `TAX_500` | 返回通用错误信息 |

### MQ 异常分类

| 类型 | 处理方式 | 示例 |
|------|----------|------|
| 可重试异常 | 抛出，触发 MQ 重试 | DB 超时、Redis 不可用、网络抖动 |
| 不可重试异常 | catch + WARN + 丢弃 | 参数格式错误、税种不支持、金额为负 |
