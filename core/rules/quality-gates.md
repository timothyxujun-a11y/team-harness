# 质量门禁规则

> 规则 ID: CORE-QUAL-001
> 严重级别: error（强制）

## CORE-QUAL-001: 变更后必须通过质量检查

代码变更后必须依次通过以下检查：

### 1. 编译检查

```bash
mvn clean compile -DskipTests
```

- 编译失败时必须修复，不得跳过。
- 不得通过注释代码或删除测试来解决编译错误。

### 2. 单元测试

```bash
mvn test
```

- 必须运行与变更相关的单元测试。
- 测试失败时必须修复，不得修改断言使其通过。
- 新增功能必须附带单元测试。

### 3. 代码审查

- 所有变更必须经过人工 Code Review。
- Code Review 关注：
  - 逻辑正确性
  - 安全性
  - 异常处理
  - 性能影响
  - 向后兼容性

### 4. 本地 Git Hook（可选）

- `pre-commit`: 编译检查 + 静态分析
- 可通过 `--no-verify` 跳过，但 CI 会做正式检查

### 5. CI 门禁（不可跳过）

- Harness 配置校验
- 生成文件漂移检查
- 规则一致性检查
- 上下文预算检查
- 编译 + 测试
- 增量覆盖率
- 敏感信息扫描
